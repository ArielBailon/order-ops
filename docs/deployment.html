OrderOps Production Deployment

One EC2 instance behind Caddy, the demo console on Vercel, releases from GitHub over OIDC and SSM

Request path

  • • The browser talks only to the console on Vercel; its server calls https://api.arielbailon.dev, so the gateway needs no CORS
  • • Only ports 80 and 443 are open; Caddy terminates TLS, and the services and Postgres stay on the compose network
  • • The gateway calls Anthropic, fails over to OpenAI (Bedrock stays off), and sends metadata-only spans to Langfuse

Release path

  • • Every change is a pull request; the ruleset requires lint, typechecks, tests, e2e with migrations, Docker builds, the console build and the eval gate
  • • A merge to master runs deploy.yml after the production approval: OIDC role, images to ECR by commit SHA, deploy.sh over SSM, smoke test, rollback to the previous SHA
  • • Vercel builds the console from the same merge

Operations and cost

  • • Nightly pg_dump to S3 (the instance can write backups, not read them) and a nightly demo data reset
  • • Logs in CloudWatch for 30 days; AWS Budgets emails at 80% of the monthly amount; chat stops at $1 of model spend per UTC day
  • • About 21 USD per month for AWS before model calls; Vercel is billed separately
